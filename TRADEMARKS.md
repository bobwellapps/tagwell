# Tagwell name and icon

Tagwell's source code is free software under the GNU General Public License,
version 3 or later (see `LICENSE`). You are welcome to use it, study it, change it
and share it under those terms.

The **Tagwell name** and the **Tagwell icon and artwork** (`tagwell.png`, the
illustrated stone well with a "Tag Well" luggage tag, a record, a CD and a cassette)
are not part of that licence. They identify the official Tagwell app published by
bobwellapps.

What this means in practice:

- You may use the name and icon to refer to Tagwell, for example in a review,
  an article, or a package of the unmodified app.
- If you publish a modified version or a fork, please give it a different name and
  a different icon, so people can tell it apart from the official app.
- Please don't use the name or icon in a way that suggests your project is the
  official Tagwell or is endorsed by its author.

Questions about using the name or icon are welcome through the project's GitHub
issues page.
